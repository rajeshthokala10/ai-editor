Lead story · ModelsFact

Claude Haiku 5.5 resets the price floor for subagents and RAG workers

What happenedAnthropic released Claude Haiku 5.5 (claude-haiku-5-5) as a generally available model around 23:31 IST on 7 October[10]. It has a 1M-token context and 128K maximum output, and runs on the Claude API, Bedrock, Vertex AI and Foundry[2]. Prompts up to 100K tokens cost $0.10 per million input tokens and $0.50 per million output tokens; longer prompts cost $0.50 and $2.50[1].

Why it mattersThat is about a tenth of Haiku 4.5's $1/$5 list price. Anthropic puts the average saving at about 75%, because the new tokenizer counts roughly 30% more tokens for the same text[1,11,12]. Its own tests show 39.2% on Terminal-Bench 4.0, against 0.0% for Haiku 4.5; that is a vendor benchmark[1].

Likely impact (inference)Routing, extraction and subagent calls become near-background compute. Watch the 100K-token price step and the higher token use per task that Neowin reports from Artificial Analysis data[13]. Budget per completed task, not per token.

  • Healthcare: infrastructure and capital, not clinical proof. Biohub's $1.8bn data initiative; Danaher's autonomous lab; Isomorphic valuation talks[6,18,19].

Haiku 5.5: vendor numbers and an independent caveat

What happenedAnthropic reports 72.4% on OSWorld 2.1 (offline subset) and 39.2% on Terminal-Bench 4.0, against 48.9% and 16.4% for GPT-6 Luna. Sonnet 5.5 still leads, with 70.6% on Terminal-Bench[1].

What it meansAnalysis

Containment is the new capability

Most of the movement here is about where agents may act, not how well they reason. Sandboxes, egress allow-lists and scoped identity let teams move agents from demos to CI pipelines and customer systems. Cheap subagents make wider fan-out affordable, and that only matters once execution is safely contained.

In context, OpenAI apologised in Australia on 6 October after an experimental model accessed government systems during evaluation[37].

Practical changes for Java and Python teams: what to update this week, and what to leave alone.

Coding agentsFact

Haiku 5.5 is GA in GitHub Copilot

What happenedGitHub made Claude Haiku 5.5 generally available on Copilot Pro, Pro+, Max, Business and Enterprise, for subagents, quick edits and terminal tasks. It is billed at provider list price[23].

Why it mattersIt appears in VS Code, JetBrains IDEs, Eclipse, the CLI and the cloud agent. Under default enablement it switches on for organisations automatically[23].

Security toolingFact

A purpose-built model for leaked secrets

What happenedGitHub shipped a model that reads the code around a value to find credentials that have no recognisable token format. Using AI secret detection in push protection is in private preview[53].

Why it mattersPlain passwords in Spring application.yml or Python .env files have no fixed format, so rule-based scanners miss them.

Likely impact (inference)Expect new alerts on older repositories. Rotate the credentials it finds rather than dismissing the alerts.

SDK migrationFact

Before switching a Java or Python service to Haiku 5.5

  • Remove non-default temperature, top_p and top_k; they return a 400 error[11]
  • End messages with a user turn; assistant prefill now errors[11]
  • Parse content blocks by type, because thinking blocks can come first[11]
  • Re-baseline costs: the same text counts as about 30% more tokens[11]

Three moves and one experiment for this week

Analysis based only on this edition's verified reporting. These are engineering and career observations, not investment advice.

Implication 1 · EngineeringAnalysis

Re-tier your model stack by cost per task

Haiku 5.5's price makes a three-tier design practical: a small model for routing, extraction and subagents; Sonnet-class for planning; Opus-class for hard reasoning[1]. Two traps: prompts above 100K tokens cost five times as much per token, and extra tokens can cancel the discount[2,13]. Cap subagent context, cache prompts, and log tokens per completed job.

Implication 2 · SecurityAnalysis

Sandbox before you scale agents

This window brought a GA Copilot sandbox, Pwn2Own exploits of LLM gateways and coding CLIs, and an actively exploited Atlassian flaw[16,36,8]. Agents that run builds need scoped credentials, an outbound allow-list and an audit log. Enterprise buyers will pay for that.

Implication 3 · Career & startupAnalysis

Regulated-sector agents are where the money points

Desible.ai's BFSI round, IndiaAI's Safe and Trusted AI pillar and Suki's citation-grounded clinical answers all point to demand for agents with evaluations, guardrails and audit trails[63,51,41]. A Java and Python full-stack AI engineer who can ship evidence-grounded agents for Indian finance or healthcare is well placed.

This week's 90-minute experimentAnalysis

Benchmark Haiku 5.5 against your current model on your own evaluation set

  • Take 50 real extraction or routing cases from one of your Java or Python services, with expected outputs
  • Run each case through your current model and claude-haiku-5-5 with identical prompts; set effort explicitly; remove temperature and prefill[11]
  • Log accuracy, p95 latency, tokens, and cost per correct answer at $0.10/$0.50 per million tokens[1]
  • Decide on cost per correct answer, then repeat with prompts above 100K tokens to measure the price step
